# Industrias Pitcoll - Catalogo (URL fija para QR)

Este repositorio publica el catalogo en la URL fija del QR eterno:
https://industrias-pitcoll.github.io/

## Como actualizar el catalogo SIN cambiar el QR

1. Sube el nuevo PDF con el **mismo nombre**: `catalogo.pdf` (reemplaza el anterior).
2. Haz commit. GitHub Pages publica la nueva version en ~1 min.

El QR NO cambia: siempre apunta a https://industrias-pitcoll.github.io/

Si el archivo cambia de nombre, edita `index.html` (2 apariciones de `catalogo.pdf`). No cambies el nombre del repositorio ni de la organizacion.
